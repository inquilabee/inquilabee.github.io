# inquilabee.github.io

Curated project index for [inquilabee](https://github.com/inquilabee) — Astro static site on GitHub Pages.

Live: [https://inquilabee.github.io](https://inquilabee.github.io)

## Develop

```bash
npm install
npm run dev
```

## Verify links before push

```bash
npm run verify
npm run build
```

## Deploy

Push to `main` — GitHub Actions deploys to GitHub Pages (`withastro/action`).

## Content

Edit `src/data/projects.json` for the catalog. Long-form blurbs live in `src/data/projectDocs.js`.
